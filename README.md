Retail Sales Data Analytics Project

Project Overview

This project analyzes retail sales transaction data using Python, SQL, and data visualization techniques to uncover business insights, sales trends, and customer behavior patterns.

The analysis focuses on:

* Top-performing products
* Country-wise revenue analysis
* Monthly sales trends
* Customer purchasing behavior
* Product performance analytics

⸻

Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* SQL
* SQLite
* VS Code

⸻

Data Cleaning Process

The dataset was cleaned using Python and Pandas by:

* Removing null customer IDs
* Removing cancelled invoices
* Removing negative quantities
* Creating a Revenue column

⸻

SQL Analysis Performed

The following SQL analyses were completed:

* Top countries by revenue
* Top products by revenue
* Highest priced products
* Top-selling products by quantity
* Monthly revenue trends
* Average revenue by country

⸻

Key Business Insights

* United Kingdom generated the highest overall revenue.
* Regency Cakestand 3 Tier was the top revenue-generating product.
* Revenue trends fluctuated monthly indicating seasonality.
* Certain countries had higher average order values despite lower sales volume.
* Several products consistently generated high sales quantities.
